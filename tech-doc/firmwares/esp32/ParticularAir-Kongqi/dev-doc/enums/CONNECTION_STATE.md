# CONNECTION_STATE

Enum values for the `wifiType.connectionState` field.

| Value | Description |
| --- | --- |
| `CONNECTED` | Successfully connected to WiFi |
| `CONNECTING` | Connection attempt in progress |
| `WRONG_PASSWORD` | Incorrect password |
| `NO_NETWORK_FOUND` | SSID not found |
| `DISCONNECTED` | No credentials saved, or explicitly disconnected |
| `ERROR` | Unknown error |
