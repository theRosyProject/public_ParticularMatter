# ParticularAir-In 1 — 3D Printed Enclosure

This folder contains documentation for the 3D printed enclosure designed for the **ParticularAir-1** (ESP8266) device.

---

## STL Files

The printable model is published on MakerWorld:

**[ParticulAIR-In 1 on MakerWorld](https://makerworld.com/zh/models/1912756-particulair-in-1)**

Download the STL files directly from that page.

---

## Designed for

The enclosure is designed to house:

| Component | Notes |
|-----------|-------|
| Adafruit Feather HUZZAH (ESP8266) | Main microcontroller |
| PMS5003 | PM2.5 air quality sensor |

See [../wiring/wiring_instructions.md](../wiring/wiring_instructions.md) for the full wiring guide.
